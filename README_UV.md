# RPClient UV（Unoffical Version）

本仓库是 [KafuuNeko/RPClient](https://github.com/KafuuNeko/RPClient) 的非官方定制分支。
上游的中英文说明保持原样不动，这个文件只记录本分支做了什么、怎么构建、有什么边界。

## 与上游的差别

### 品牌与打包

- 应用显示名：`RPClient UV`，`applicationId` 为 `me.kafuuneko.rpclient.uv`，可与上游版本共存安装。
- 关于页新增「定制版版本」，格式为 `UV <定制版号> · 上游 <上游版本>`，一眼能分辨装的是哪一份。
- 签名与维护：`yes a hit`。

### 语言

默认界面语言固定为简体中文，不跟随系统语言；其余 12 个语言目录保持与上游同步。

### 剧本系统（本分支新增）

- 剧本以 JSON 描述：场景、条件、检查点、多入口、解锁关系、角色白名单与禁止名单、
  时间轴（轮次上限，0 为不限）、GM 与骰子开关；上层支持剧本集。
- 格式规范见 [doc/剧本格式.md](doc/剧本格式.md)。
- 编排为表格化：点选链接建立后继与解锁关系，场景可改名、设轮次、设开场、设为入口、删除。
- 运行时判定：关键词、正则、轮次上限；**先判失败后判通关**，
  通关后按剧本设置转入自由模式。判定不交给模型解释，保证同一段对话可复现结局。

### 小说导入

整本 TXT/Markdown 自动分章，支持多文件散装章节。序号识别覆盖中文数字（`第十二章`）、
阿拉伯数字（`7`）、小数（`1.5`）、裸数字前缀（`003`）；散装文件按序号数值排序，
`第X卷` / `Volume N` 自动分卷并归卷。导入后可按需调用模型提取角色卡与世界书。

### 助手

独立的沙箱助手页：文件、角色卡、世界书、剧本四类工具，沙箱限定为应用私有目录。
支持把图片（多模态）与文本作为附件随消息发送。

### 计费

消耗统计页除 Token 外增加余额查询与金额估算：内置常见模型的 CNY 分档价，
按请求时段与模型匹配计价；无内置价的模型回退到 OpenRouter 美元价 × 可配置汇率。

## 构建

前置条件：JDK 17、Android SDK（`compileSdk` 36.1、`minSdk` 26）。

```bash
# 本地
./gradlew assembleDebug testDebugUnitTest

# 产物发布到 dist 并带版本号命名
pwsh -File tools/publish-apk.ps1 -Install
```

推送 `master` 会自动触发 CI：跑单元测试、构建 debug 包，
并以 `v<定制版号>` 为标签发布到 Releases，产物名形如
`rpclient-2026.3.1-dev-debug-v0.17.apk`。

## 边界与免责

- 这是 debug 签名的个人定制分支，**不适合直接上架分发**。
- 剧本、助手等新增功能需要自行配置模型服务；本仓库不含任何密钥。
- 与上游的合并策略：上游文件尽量保持原样，只在必要处做最小改动，
  以便持续同步上游更新。
