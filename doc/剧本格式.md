# 剧本包格式（Script Pack）

剧本包是一套可独立导入、分发的角色扮演剧本，把「设定」和「流程」分开描述：设定落成普通世界书，流程由场景与条件描述，运行时再解释。

当前结构版本：`formatVersion = 1`。

## 顶层字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `formatVersion` | int | 结构版本，缺省为 1；高于应用支持的版本会被拒绝 |
| `id` | string | 剧本唯一标识，导入时用于去重 |
| `name` | string | 展示名称 |
| `description` | string | 简介 |
| `mode` | enum | `Mainline`（主线）/ `Loop`（循环）/ `Free`（自由） |
| `globalLorebook` | object | 全局世界书，整局都参与 Prompt |
| `scenes` | array | 场景列表，顺序即推荐推进顺序 |
| `startSceneId` | string | 起始场景，缺省取第一个场景 |
| `startSceneIds` | array | 多入口场景列表，用于多主角各自开线的剧本 |
| `freeModeAfterClear` | bool | 通关后是否进入自由模式，缺省 `true` |
| `enableGm` | bool | 是否启用 GM（游戏主持人）叙述层，缺省 `true` |
| `enableDice` | bool | 是否启用骰子判定，缺省 `true` |

## 场景字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 场景标识，必须唯一 |
| `name` | string | 场景名称 |
| `entryPrompt` | string | 进入场景时插入的一次性开场描述 |
| `lorebook` | object | 局部世界书，只在当前场景生效 |
| `nextSceneIds` | array | 后继场景 ID；为空表示终点 |
| `loopEnabled` | bool | 是否允许重复进入（循环模式常用） |
| `checkpoint` | bool | 是否作为失败回滚的检查点 |
| `failConditions` | array | 失败条件，命中即判定失败 |
| `completionCondition` | object | 通关条件，命中即判定完成 |
| `cast` | array | 允许出场的角色；为空表示不限制 |
| `bannedCast` | array | 禁止出场的角色名，优先级高于 `cast` |
| `maxRounds` | int | 本场景最多进行的对话轮数，`0` 表示不限（时间轴） |
| `unlockedBy` | array | 前置场景；都经历过才解锁，为空表示一开始可达 |
| `layout` | object | 图形化编辑器的节点坐标 `{x, y}`，手写时可省略 |

### 三种写法

**极简单线**（轻松小品，不写任何路由字段）：

```json
{"id": "light", "name": "轻松小品", "scenes": [{"id": "only", "name": "唯一场景"}]}
```

**主线推进**（`nextSceneIds` 串成链，可带失败条件与检查点）。

**多线攻略**（多女主 gal，顺序不定，靠 `unlockedBy` 解锁）：

```json
{
  "startSceneIds": ["a-start", "b-start"],
  "scenes": [
    {"id": "a-start", "name": "A 线开始"},
    {"id": "b-start", "name": "B 线开始"},
    {"id": "a-mid", "name": "A 线中段", "unlockedBy": ["a-start"]},
    {"id": "final", "name": "汇合", "unlockedBy": ["a-mid", "b-mid"]}
  ]
}
```

`unlockedBy` 是「前置场景都经历过」而不是「必须按顺序」——两条线可以任意顺序推进，汇合点自然会等两边都完成。

### 图形化编辑

`layout` 只存坐标，**不存连线**：画布上的箭头由 `nextSceneIds` 与 `unlockedBy` 推导，
保证图上的连线与运行时可达性永远来自同一份数据，不会出现「图上连着、实际打不开」。

### 出场角色

剧本是外部文件，无法预知本地角色卡 ID，因此按**名称**匹配：

```json
"cast": [
  {"name": "老陈", "required": true, "description": "港口唯一的引水员，右手有旧伤。"}
]
```

- `required` 为 `true` 时该角色必须在场；`false` 允许缺席。
- `description` 是剧本自带的设定，导入时本地没有同名角色卡就按它自动创建。
- `bannedCast` 里的名字**不允许**同时出现在 `cast` 里，同时出现会在校验阶段直接报错——运行时无法判断这个角色到底能不能说话。

## 条件类型

| `type` | 用到的字段 | 判定方式 |
| --- | --- | --- |
| `Keyword` | `pattern` | 最近消息命中关键词 |
| `Regex` | `pattern` | 最近消息命中正则 |
| `RoundLimit` | `threshold` | 本场景对话轮数达到阈值 |
| `ScoreAtLeast` | `threshold` | 场景评分达到阈值 |

条件只做确定性判定，不交给模型解释；`description` 用于失败时给玩家的说明。

## 世界书结构

```json
{
  "name": "设定集名称",
  "entries": [
    {"name": "条目名", "content": "设定正文", "keys": ["触发词"], "constant": false}
  ]
}
```

`keys` 为空且 `constant` 为 `true` 时按常驻条目注入；两者都缺省时导入后仍可手工补关键词。

## 完整示例

```json
{
  "formatVersion": 1,
  "id": "fog-harbor",
  "name": "雾港",
  "description": "三夜之内找出港口的叛徒",
  "mode": "Mainline",
  "startSceneId": "night-1",
  "freeModeAfterClear": true,
  "globalLorebook": {
    "name": "雾港·全局",
    "entries": [
      {"name": "雾港", "content": "常年大雾的深水港，进出船只要靠引水员。", "keys": ["雾港", "港口"], "constant": true}
    ]
  },
  "scenes": [
    {
      "id": "night-1",
      "name": "第一夜",
      "entryPrompt": "你抵达雾港，码头只剩一盏灯亮着。",
      "nextSceneIds": ["night-2"],
      "checkpoint": true,
      "lorebook": {
        "name": "雾港·第一夜",
        "entries": [
          {"name": "引水员老陈", "content": "港口唯一的引水员，右手有旧伤。", "keys": ["老陈", "引水员"]}
        ]
      },
      "failConditions": [
        {"type": "RoundLimit", "threshold": 30, "description": "天亮前没能问出线索"},
        {"type": "Keyword", "pattern": "被杀", "description": "你在码头遇害"}
      ]
    },
    {
      "id": "night-2",
      "name": "第二夜",
      "entryPrompt": "仓库区的灯灭了一半。",
      "nextSceneIds": [],
      "loopEnabled": true,
      "completionCondition": {"type": "Keyword", "pattern": "交出名单", "description": "主线完成"}
    }
  ]
}
```

## 剧本集（Script Collection）

剧本集是比剧本包更上层的容器，用来组织一部作品的多个剧本（正篇、支线、番外），并给出整集默认开关。

```json
{
  "formatVersion": 1,
  "id": "fog-harbor-series",
  "name": "雾港系列",
  "description": "正篇与两篇支线",
  "enableGm": true,
  "enableDice": true,
  "packs": [ { "id": "fog-harbor", "name": "雾港", "scenes": [] } ]
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `formatVersion` | int | 与剧本包共用同一套版本号 |
| `id` / `name` | string | 剧本集标识与名称，必填 |
| `description` | string | 简介 |
| `packs` | array | 集内剧本包，按推荐游玩顺序排列 |
| `enableGm` | bool | 整集默认是否启用 GM |
| `enableDice` | bool | 整集默认是否启用骰子 |

集内每个剧本包都会按单包规则完整校验，**任一包不合法则整个剧本集拒绝导入**；
剧本集内的 pack ID 也必须唯一。

## 校验规则

解析时会依次检查，任何一步失败都返回具体原因：

- 必须是单个 JSON 对象（允许被 Markdown 代码围栏包裹）；
- `formatVersion` 不得高于应用支持版本；
- `id`、`name` 必填，`scenes` 不能为空；
- 场景 ID 不能重复；
- `startSceneId` 必须是已存在的场景；
- `nextSceneIds` 引用的场景必须存在，悬空引用会让主线中途断掉；
- 同一场景里，角色不能同时出现在 `cast` 与 `bannedCast` 中；
- 剧本集内 pack ID 不能重复，且每个 pack 都要单独通过上述校验。

缺失的可选字段按空串 / 零 / `false` 处理，不会被当成致命错误。
